Entry for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on make.fun.

`main.ts` writes a single pickup line — 123 characters, spoken by a vending
machine to a passing human — to `/output/entry.txt`:

> Hey, you — press B7. I've been saving the last one behind the glass just for you, and my coils never jam for the cute ones.

Run it with Node 22.18 or later:

```sh
node main.ts
```
